# StyLow — Fashion E-Commerce Platform

StyLow is a fashion e-commerce platform designed to make fashion discovery and product management simple, intuitive, and accessible through a modern digital experience.

The platform provides a user-facing shopping experience alongside an administrative interface for managing the product catalog.

## Overview

StyLow brings essential e-commerce functionality into a single platform, allowing users to explore fashion products while providing administrators with tools to manage the available catalog.

The platform consists of two main experiences:

- **Customer Experience** — Discover and explore fashion products through a responsive interface.
- **Admin Experience** — Manage products and maintain the fashion catalog.

## Features

### Product Discovery

- Browse available fashion products
- View detailed product information
- Explore product collections
- Navigate products through an intuitive interface
- Responsive experience across screen sizes

### Product Management

- View product catalog
- Add product information
- Update product information
- Manage available products
- Maintain product data through the administrative interface

## User Experience

StyLow focuses on making product discovery straightforward and visually engaging.

The interface is structured around clear navigation, product-focused layouts, and responsive components to help users explore products with minimal friction.

## Tech Stack

- **Backend:** Java
- **Frontend:** HTML, CSS, JavaScript
- **Design:** Figma
- **Architecture:** Object-Oriented Programming
- **API:** REST API
- **Version Control:** Git
